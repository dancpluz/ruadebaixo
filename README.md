## 📚 About

**Rua de Baixo** is my most ambitious project, a journey of more than two years that transformed a small thrift shop with friends into a full-fledged clothing brand. This repository documents every step of that evolution, from my first lines of code to a robust, modern e-commerce platform. It's a testament to the power of self-taught development and hands-on learning, where every branch tells a unique story of growth. The brand name and logo are formally registered with INPI in Brazil, reflecting its official status as a commercial entity.

What started as a collaborative idea among five friends to sell second-hand clothes evolved into a serious brand with its own identity. Faced with the need for a digital storefront, I took on the challenge of learning web development from scratch. Through countless tutorials and relentless trial-and-error, I built this platform from the ground up, with key support from some of the founding members.

This project isn't just a website; it's a living archive of my developer journey. Each branch represents a major milestone, a new challenge, and a deeper understanding of web technologies and business needs.

## 🚀 The Evolution of the Project

### The `prev` Branch - 2023

<picture>
    <img src="screenshots/ia.gif" align="right" width="30%" alt="Image of the first version of the website, prev branch"/>
</picture>

The very first version. This site was a manual solution for selling clothes. It used a basic front-end to showcase products, with sales handled via a local WhatsApp automation script hosted on my home server. This was the foundation where everything began.

### The `v1` Branch - 2024

<picture>
    <img src="screenshots/ia.gif" align="right" width="30%" alt="Screenshot of the v1 branch website with Strapi and Stripe integration"/>
</picture>

This version marked a significant upgrade. I integrated a local **Strapi** database to manage products and content, which was a huge leap from static files. It also included the first payment integration with **Stripe**, allowing for a more automated e-commerce flow and a more creative design.

### The `v2` Branch

<picture>
    <img src="screenshots/ia.gif" align="right" width="30%" alt="Screenshot of the v2 branch with a new design and Asaas payment integration"/>
</picture>

Building on the success of `v1`, this version brought a near-complete redesign. We switched payment gateways to **Asaas** via their API, enabling automatic payments via Pix and credit cards—a crucial feature for the Brazilian market.

### The `v3` Branch (main)

<picture>
  <a href='https://ruadebaixo.com.br'>
    <img src="screenshots/ia.gif" align="right" width="30%" alt="Screenshot of the current v3 main branch, with a new and robust design"/>
    </a>
</picture>

This is the current and most ambitious version. The site has been completely redesigned for a more robust, secure, and performant user experience. This version is the foundation for the brand's future growth.

  * **Live Site:** [ruadebaixo.com.br](https://ruadebaixo.com.br)

### The `ia` Branch (Special Project)

<picture>
  <a href='https://ia.ruadebaixo.com.br'>
    <img src="screenshots/ia.gif" align="right" width="30%" alt="GIF of the special ia branch, a Windows XP-themed virtual art gallery"/>
    </a>
</picture>

This branch is a unique departure from the e-commerce model. It's an artistic side project: a virtual gallery for artists, styled with a nostalgic **Windows XP** aesthetic. It's a satirical commentary on the rise of LLM art generation, showcasing a different kind of creativity.

  * **Live Site:** [ia.ruadebaixo.com.br](https://ia.ruadebaixo.com.br)

## 🛠 Built With

<p align="left">
  <img src="https://skillicons.dev/icons?i=nextjs,react,js,ts,tailwind,styledcomponents" \>
</p>

  * **Next.js** - The framework used for all versions.
  * **Styled Components** - For initial styling in earlier versions.
  * **Tailwind CSS** - The primary styling framework for current versions.
  * **Strapi** - Self-hosted headless CMS for content management.
  * **Stripe** - First payment gateway integration.
  * **Asaas** - Second payment gateway integration (via API).
  * **Sanity** - Used for content management in later versions.
